# 内容运营助手

**把人员、平台账号、视频素材和发布任务放进一个中文桌面工作台。**

适合需要管理多个运营账号、准备视频草稿、跟踪执行结果和整理内容定位的个人与小团队。当前源码版本为 **0.6.0**，发布引擎基于 MatrixMedia。

[下载最新版源码](https://github.com/xiaoguobaqun/content-ops-assistant/archive/refs/heads/main.zip) · [快速上手](#快速上手) · [完整操作手册](docs/user-guide.md) · [从源码运行](docs/development.md) · [全部文档](docs/README.md)

## 能做什么

- **管理人员与账号**。每个人按平台绑定账号，同平台可保存多个账号的登录状态，工作台可直接调整绑定。
- **准备视频与封面**。拖入或选择本机视频，填写标题和简介，自动生成封面或选择已有图片。
- **执行任务并追踪结果**。单平台选择草稿或已开放的发布方式，多平台顺序保存草稿，按操作日期查找记录，查看回查报告。
- **建立内容定位**。自主填写业务资料，配置 OpenAI、Claude 或 DeepSeek 文字接口，预览材料后生成并确认画像建议。

## 快速上手

1. **连接账号**。进入“人员与账号”，选择平台、填写本机账号名，获取二维码，用平台 App 扫码。官方窗口要求短信等本人验证时，在该窗口完成。
2. **选择发布入口**。单个账号使用“单平台发布 / 草稿”。多人或多平台先创建人员并绑定账号，再使用“多平台存草稿”。
3. **准备内容**。拖入一个本机视频，填写标题、简介和封面，点击“生成封面并准备任务”。
4. **检查后执行**。核对人员、平台、账号和执行方式，点击“执行任务”或“执行批量草稿”，按确认窗口继续。
5. **查看结果**。在“任务记录”查看状态。出现“待核实”时，打开详情点击“回查结果”，阅读报告后处理。

账号绑定、公开与私密选项、日期筛选、回收站和 AI 配置的详细步骤见操作手册。[阅读完整操作手册](docs/user-guide.md)

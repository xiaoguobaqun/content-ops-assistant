## 仅上传程序

本次发布为净化后的源码快照，包含桌面程序、修改后的MatrixMedia引擎、测试代码、必要界面资源及许可证。引擎源码已展开在`engine/MatrixMedia`，主仓库不依赖外部子模块才能取到完整代码。

排除本机任务、账号记录、登录态、Cookie、用户视频和图片、日志、截图、开发验证手记、原主项目提交历史及本机应用包。示例账号和路径均使用占位内容。本机原项目、资料和运行数据保留原样。

`content-ops-assistant-v0.3.2-source.zip`为完整源码包，`SHA256SUMS.txt`为校验值。由于现有应用包含本机项目路径，本次不上传应用压缩包；在目标目录准备依赖后重新构建。

## 还原与能力边界

```sh
git clone https://github.com/xiaoguobaqun/content-ops-assistant.git
cd content-ops-assistant
```

源码快照包含引擎源码，不包含node_modules和本地运行时。按README准备Node20、ffmpeg、ffprobe、Python3和引擎依赖，再构建。应用仍面向本机macOS环境，本次发布没有增加跨机器独立安装能力。

抖音和视频号测试草稿已有既定实机验证；小红书登录已验证，草稿仅通过离线测试，实机验收未完成，执行继续关闭。GitHub发布不执行任何内容平台操作。

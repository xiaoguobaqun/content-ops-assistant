# v0.4.0 · 人员绑定与批量草稿源码

本次在现有私有仓库更新净化源码，包含完整 MatrixMedia 引擎和 Windows 适配交接说明。

## 新增功能

- 每人每平台绑定一个账号，同一账号不能同时归属两个人。
- 工作台按人员带出各平台账号，共用视频、文案和封面，一次确认后顺序保存草稿。
- 批次汇总各平台独立结果，保留素材指纹、父子关联、跨进程锁、防重复和中断恢复；成功或已开始的平台不重跑。
- 保留原单平台入口；待验收或未处理项不显示为全部完成。

Mac 本机版本完整离线测试79项通过，桌面构建、签名和源码一致性检查通过。净化快照另在上传前执行离线回归；这些结果不代表 Windows 或新增真实平台发布已验收。

## Windows 交接

克隆本仓库后先读 `README.md` 和 [`docs/windows-porting.md`](../windows-porting.md)。引擎已展开在 `engine/MatrixMedia`，无需拉取子模块。当前脚本、进程保护和文件锁仍有 Mac/POSIX 依赖，尚不能直接在 Windows 运行或安装，本次没有提供 Windows 安装包。

## 能力与隐私边界

人员批次只存草稿。抖音和视频号沿用既有草稿能力；小红书草稿仍待实机验收并保持执行关闭。正式三平台联发尚未开放。

附件仅有源码 ZIP、SHA-256 校验文件和源码清单；不提供 Mac 应用包。账号、人员、Cookie、任务、用户素材、日志、截图、本机验证记录和原主项目历史均不上传。GitHub更新不登录或操作内容平台。

## 任务状态与保护

| 状态 | 含义与操作 |
| --- | --- |
| 已准备 | 素材与内容已登记，核对后可执行 |
| 执行中 | 已保存状态并持锁，等待本次结果 |
| 草稿已核实 | 按该平台的草稿恢复和保留方式完成核验 |
| 作品已核实 | 找到符合本次任务的作品，审核状态继续以平台证据为准 |
| 待核实 | 结果、范围或证据仍不足，先回查并阅读报告 |
| 已作废 | 账号移除、代次或绑定变化等导致旧任务失效，需重新准备 |

准备任务保存视频、封面及内容指纹，执行前再检查变化。开始前先保存状态并持锁，中断、超时或结果不明时保留待核实，避免重复上传。

作品创建、可见范围和平台审核分别判断。抖音已唯一匹配到新作品时，会保存作品编号，即使后续范围查询失败也保留创建证据，范围继续标为待核实。发布前作品列表不完整时，系统保留拦截和查询失败原因。

作品回查使用查询路径。抖音、视频号草稿核验会恢复并在必要时原样暂存，保留“继续编辑”入口。小红书核验使用只读恢复，关闭页面后独立回读确认草稿保留。

停止操作会取消后续提交并清理后台进程。账号登录态由引擎管理。任务回收站只调整本机记录的显示位置，恢复后沿用原执行状态。

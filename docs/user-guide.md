# 操作手册

[返回首页](../README.md) · [文档导航](README.md) · [源码运行准备](development.md)

本手册从桌面工作台已经打开开始。当前公开下载采用源码形式，首次运行请先完成环境准备。

## 认识四个入口

| 入口 | 常用操作 |
| --- | --- |
| 发布工作台 | 选人员或账号、拖入视频、准备任务、确认执行 |
| 任务记录 | 按日期或状态查找、查看详情、回查结果、删除和恢复记录 |
| 人员与账号 | 扫码连接、创建人员、绑定账号、移除账号、建立内容定位 |
| 系统状态 | 检查运行环境、查看平台接入状态、配置 AI 接口 |

## 连接账号

1. 打开“人员与账号”，在连接区域选择平台。
2. 输入一个容易辨认的本机账号名，例如“品牌主号”。同平台的其他账号可用“品牌副号”等名称。
3. 点击“获取登录二维码”，使用对应平台的 App 扫码。
4. 按官方登录窗口的提示完成本人验证，等应用回读登录状态。
5. 在“已添加的账号”中确认状态显示“已连接”。

抖音登录会打开官方窗口。手机提示成功后，如果电脑仍要求短信或其他验证，请在官方窗口完成。二维码加载取决于平台页面与网络；以电脑端回读结果判断本次连接是否完成。

同平台可分别保存多个账号登录，执行时选择目标账号，任务依次运行。账号名的主要前缀要不同。`品牌-A` 和 `品牌-B` 在现有引擎中可能共用登录位置，应用会拦截这类冲突。

## 创建人员与绑定账号

1. 在“人员与账号”创建人员。
2. 为该人员选择各平台账号，每个平台可绑定一个。
3. 保存后回到工作台，选择该人员查看本次平台账号。

同一平台账号同时归属一位人员。还没有平台账号时，也可以先创建人员并填写内容定位。

在发布工作台点击“人员绑定”也能调整绑定。保存后，工作台会更新选择。改名或改绑后，已有待执行任务需要重新准备。

## 单平台准备与执行

1. 打开“发布工作台”，选择“单平台发布 / 草稿”。
2. 选择平台与目标账号。
3. 选择执行方式。抖音提供“保存草稿”“私密发布”“公开发布”，具体范围还可在“谁可以看”中核对。视频号当前使用草稿方式，小红书执行仍受门槛限制。
4. 将一个本机视频拖入素材区域，或点击该区域选择文件。
5. 填写标题和简介。封面可从视频自动生成，也可点击“选择图片”。
6. 点击“生成封面并准备任务”，检查预览与本次内容。
7. 点击“执行任务”，按确认窗口核对账号、标题和可见范围后继续。
8. 到“任务记录”查看执行结果。

拖入视频完成素材选择，后续准备和执行各有独立步骤。准备后修改视频、封面或文案，需要重新准备任务。

视频号的工作台标题会放在平台描述开头。选填的“视频号短标题”需为 6～16 个字，并符合页面提示。

## 按人员保存多平台草稿

1. 选择“多平台存草稿”。
2. 选择人员，检查自动带出的各平台账号，勾选本次使用的平台。
3. 选择共用视频、标题、简介和封面。
4. 点击“生成封面并准备任务”，再点击“执行批量草稿”。
5. 在确认窗口查看本次执行项和待验收项，确认后按平台顺序执行。
6. 在“任务记录”展开批次，分别查看各平台结果。

本入口用于多平台草稿。抖音私密或公开发布从单平台入口操作。小红书仍按当前门槛暂停执行。批次包含小红书时，共用标题最多 20 字。

停止后可查看尚未开始的平台。已开始的平台保留原结果，出现待核实项时先回查，再按界面提示处理剩余任务。

## 筛选、删除和恢复任务记录

进入“任务记录”，可按状态、标题或账号搜索，也可在“操作日期”的“从”“至”选择日期范围。

日期取最近一次执行或回查时间，尚未执行的任务按创建时间筛选。“清除日期”恢复完整日期范围。

点击“删除记录”并确认后，记录移入本机回收站。在“回收站”点击“恢复记录”可放回列表，执行状态沿用原记录。删除的范围是本机列表记录，平台作品、草稿、素材和执行证据会保留。

## 回查结果与报告

1. 找到需要核实的任务，点击“查看详情”。
2. 点击“回查结果”。
3. 回查结束后，在详情中的“回查报告”阅读结论、检查项和下一步建议。
4. 分别核对草稿或作品是否存在、可见范围是否已知、平台审核状态是否已知。

“待核实”表示现有证据还不足以确认结果。先回查再处理，避免重复提交。平台列表有时延迟更新，可以稍后再次回查。

历史报告按次保留。旧任务可通过新一次回查生成报告。草稿核验会使用各平台对应的恢复与保留流程，具体范围列在状态说明中。[阅读任务状态与保护机制](platform-status.md#任务状态与保护)

## 移除账号并退出本机登录

1. 若账号已经绑定人员，先将该人员对应平台改为“暂不绑定”并保存。
2. 等后台操作结束，在“已添加的账号”找到目标账号。
3. 点击“移除账号”，检查平台和账号名，确认“移除并退出登录”。

移除会清理该账号在此应用中的登录登记与凭据，尚未执行的旧任务作废。重新连接同名账号后需重新准备任务。历史任务、人员画像、素材和草稿存储保留。遇到共享或异常登录分区时，应用会提示处理。

## 内容定位与 AI

在“人员与账号 → 内容定位”选择人员，自主填写业务、产品或服务、运营目标，保存基础资料。资料可以先保存为不完整草稿，预览或分析前再补齐必填项。

需要 AI 建议时，在“系统状态 → AI 接口设置”填写文字服务，回到内容定位预览材料，选择服务并生成候选画像。修改后点击“确认采用这版画像”。[查看 AI 配置完整步骤](ai-setup.md)

## 常见情况

| 遇到的情况 | 处理方法 |
| --- | --- |
| 手机已显示登录成功，电脑仍在等待 | 查看官方窗口是否还有短信等本人验证，完成后等待回读 |
| 提示“提交前作品列表不完整” | 保留当前任务，查看错误原因并稍后回查或重试查询，保留发布前检查 |
| 中断、超时或结果待核实 | 打开任务详情回查，按报告处理 |
| 提示素材或内容变化 | 使用当前视频、封面和文案重新准备任务 |
| 环境显示需处理 | 在“系统状态”查看对应检查项，并参照源码运行说明补齐环境 |
| 关窗口后应用仍在运行 | 窗口关闭会隐藏应用，通过应用菜单的“退出内容运营助手”结束程序 |

需要反馈问题时，提供系统、版本、错误原文和脱敏后的复现步骤。密钥、Cookie、验证码和客户资料请保存在本机。

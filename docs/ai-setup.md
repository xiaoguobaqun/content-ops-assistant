# 填写AI接口与建立内容定位

本机0.5.0提供OpenAI、Claude、DeepSeek三项独立配置。当前没有填入或调用任何真实密钥，已有图片生成密钥不会自动导入。

## 填写接口

打开桌面应用的“系统状态”，找到“AI接口设置”，填写所需服务的接口地址、文字模型名称和API密钥，然后保存。不需要把密钥发到聊天中。

| 配置项 | 默认地址 | 请求协议 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | Chat Completions |
| Claude | `https://api.anthropic.com/v1` | Claude Messages |
| DeepSeek | `https://api.deepseek.com/v1` | Chat Completions |

模型名称由你按服务商实际支持的文字模型填写。接口地址填写基础地址，程序会追加`/chat/completions`或`/messages`，不要重复填写完整请求路径。也可以改用相应协议的中转地址；OpenAI配置支持兼容Chat Completions协议的接口。地址支持HTTPS，以及本机回环HTTP。

保存允许只保留地址和模型，等以后补密钥。已有密钥时，密钥框留空会沿用这一项已保存的密钥；更换接口地址需要重新填写密钥。密钥使用系统加密保存，界面不会回显原密钥。

“已配置，未测试”表示配置字段已齐全；保存不会发送测试请求，也不表示服务商已验证可用。本轮三家协议均只使用模拟响应验证。第一次使用可以先建一个合成示例档案，明确点击分析后检查服务是否可用。

## 给新客户建档

1. 打开“人员与账号”，创建人员；账号可以暂不绑定。
2. 在“内容定位”选择该人员和“自主填写”。填写业务、产品或服务、运营目标；受众及优势限制可选，不清楚的内容交给AI提出建议。
3. 保存基础资料。保存仅写本机，不调用AI。
4. 预览本次分析材料，选择已配置的服务，再点击“生成画像建议”。点击后才把预览的文字和指标发往该服务。
5. 检查并修改AI建议，点击“确认采用这版画像”。后续分析失败或取消时，原确认版本保留。

“分析已有账号”的真实读取仍待逐平台核实本人身份、作品归属和字段口径，暂不可执行。当前先使用自主填写流程，不会以空数据冒充账号分析。

## 本机资料

人员、画像、样本及接口配置都保存在被Git忽略的`.local/`，不进入源码包、应用包或GitHub。调用云端AI时会发送你选择的分析材料；登录态、Cookie、素材文件和其他客户档案不会自动附带发送。

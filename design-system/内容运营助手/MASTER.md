# 内容运营助手桌面设计系统

参考：GitHub anthropics/skills/frontend-design（a5333457c414d20d625f307df945842c0952ecc3）和 nextlevelbuilder/ui-ux-pro-max-skill。已运行设计系统生成；覆盖不适合桌面操作工具的营销落地页结构。

- 画布 #F5F7F8，纸面 #FFFFFF，文字 #1F2933，次级 #66737F，主要操作 #087F75，待核实 #98610F。
- 字体采用本机 PingFang SC / Apple 系统字体。主标题 27px，输入 13px，标签 12px，次级说明 11px。
- 左导航 224px，中央可编辑表单，右侧 310px 预览。圆角区分：按钮 8px、工作面 14px。
- 主要顺序：选择素材 → 准备任务 → 执行与核验。每个状态基于真实数据。
- 不使用虚构数据或装饰性大数字，不引入网络字体、CDN、营销横幅和自动播放动画。
- 统一 SVG 线性图标，键盘焦点可见，低动态偏好有效。运行中的提示显示经过时间，不伪造上传百分比。
